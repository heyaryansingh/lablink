# Plan 10-01 - Web Platform Beta

Date: 2026-05-18  
Phase: 10 - Web Platform  
Completion promise: `LABLINK_WEB_PLATFORM_BETA_READY`

## Objective

Convert Lab Link from terminal-only beta into a dual-surface product with a refined browser workspace that is still npm-installable, zero-dependency at runtime, and honest about real AI and integration credentials.

## Scope

- Add PRD v2.4 for the website, design system, navigation customization, meeting intelligence, and integration readiness.
- Add `lablink web` and `npm run web`.
- Add a static website served by a Node built-in HTTP server.
- Add API routes for local state, integration status, rules-based meeting extraction, provider-backed meeting analysis, and real Zoom meeting creation.
- Add browser Meeting Studio with agenda, transcript, live notes support, rules extraction, real AI analysis button, and Zoom creation button.
- Add drag-reorderable workspace tabs, density controls, persistent layout preferences, and a professional visual system.
- Update README, package publishing files, and release checks.

## Constraints

- No fake AI responses.
- No fake Zoom meeting URL.
- No copied third-party product code.
- No React/Vite dependency chain in the beta web runtime.
- Rules-based local extraction is allowed only when labeled as rules-based.
- Missing credentials must produce setup guidance rather than pretend success.

## Verification

- `node bin/lablink.mjs web --smoke`
- `npm run web:smoke`
- `npm run validate`
- `npm run release:check`
- Manual local server start for browser testing URL
